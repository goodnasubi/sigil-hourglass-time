# sigil-hourglass-time の概念と設計方針

## 位置づけ

Sigil のバックエンド系部品のひとつ。2026-11-22 に池田さんが決定した。

- **hourglass** ＝ 砂時計。時を刻む道具をテーマ語にした。
- **time** ＝ 時刻。全部品で揃える対象そのもの。

## 役割

Sigil の全部品の時刻を揃える時刻同期（NTP のサーバーとクライアント）を提供する。

ログの突き合わせ、証明書の有効期限の検証、トークンの有効期限の判定は、すべて正しい時刻が土台になる。部品ごとに時刻がずれていれば、監視は事実を追えず、検証は正しく働かない。その土台を自分たちで持つための部品である。

## 他部品との連携（将来像）

- 各部品の時刻のずれを検知し、sigil-argus-observe へ知らせる。時刻のずれは障害の兆候でもあるため、観測の対象に含める。
- sigil-rune-auth のトークン有効期限の判定や、sigil-shield-tls の証明書検証が、正しい時刻を前提にできるようにする。
